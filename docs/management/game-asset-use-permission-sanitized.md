# Permission to Use Unmodified Game Assets

## Record status

This is a privacy-sanitized record of an email received from the publisher of
*Dyson Sphere Program*. The original `.eml` remains privately held by the
project owner and is not stored in this repository.

This record preserves the substance and context of the permission while
masking personal names, email addresses, account names, and mail-routing
metadata. Every masked personal identifier retains only its first and last
character; all intervening characters are represented by asterisks.

## Working scope

The publisher granted permission to use **unmodified in-game images of items,
technologies, and other game assets** in:

- the DSP Practical Progression Guide; and
- the related DSP Guide Check mod materials.

The permission is limited to the current **non-commercial community project**
described in the request. This record does not infer permission for modified
assets, commercial use, standalone asset redistribution, or unrelated
projects.
