# DSP Guide Check Maintenance Roadmap

## Status and authority

DSP Guide Check is in maintenance mode. No implementation story, release gate
or validation checkpoint is active.

[`PROJECT.md`](PROJECT.md) is the authority for the current product contract,
supported guide and compatibility state. Completed planning and acceptance
records are retained in the [documentation archive](archive/README.md) and do
not create active work.

## Maintenance intake

New work begins only from:

- a meaningful change to the published guide;
- a reproducible defect or compatibility regression;
- an accepted feature request within the existing product scope; or
- required maintenance of the game, BepInEx, build or package contract.

An observation, archived proposal or newer CI build is not active work until the
release owner authorizes a bounded story.
