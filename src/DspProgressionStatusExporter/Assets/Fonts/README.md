# Basic font source

`Basic-Regular.ttf` is the unmodified Basic Regular font distributed by
Google Fonts. It is embedded in DSP Guide Check for the panel presentation.

- Family: Basic
- Style: Regular (400)
- Source: <https://github.com/google/fonts/tree/main/ofl/basic>
- License: SIL Open Font License 1.1; see `Basic-OFL.txt`

The font-family change does not alter the panel's established sizes, spacing,
colors, outlines, or interaction styles. The `DON'T PANIC` control retains its
separate Comic Sans presentation.
